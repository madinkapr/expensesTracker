1.1 Loyiha maqsadi
ExpenseWise - bu foydalanuvchining har kungi xarajatlarini yozib borish, ularni kategoriyalarga ajratish, oylik budjetni 
kuzatish va grafiklar orqali tahlil qilish uchun mo'ljallangan web platforma. Platforma Android ilovadagi asosiy qulayliklarni 
web formatga olib chiqadi: xarajat kiritish, ro'yxat ko'rish, oylik grafik, budjet nazorati va hisoblar kesimida balansni kuzatish.
1.2 Muammo va yechim
Mavjud muammo Taklif etilgan yechim
Xarajatlar daftar yoki turli joylarda tarqoq saqlanadi Barcha xarajatlarni bitta web ilovada jamlash
Qaysi kategoriya ko'proq pul olayotgani aniq ko'rinmaydi Kategoriya bo'yicha grafik va oylik tahlil
Oylik budjetdan qancha qolgani qo'lda hisoblanadi Real-time budget tracking va spent/left ko'rsatkichi
Bir nechta hisoblar bo'lsa nazorat qilish qiyin Accounts moduli orqali alohida balans yuritish
Kundalik xarajatlarni keyin qidirish noqulay Date, category, tag va search bilan tez topish
1.3 Maqsadli auditoriya

expensewise.uz  |  Maxfiy hujjat  |  Sahifa 1210. Xavfsizlik talablari
10.1 Autentifikatsiya xavfsizligi
• Parol kamida 8 belgidan iborat bo'lishi kerak.
• Parollar bcrypt orqali hash qilinadi.
• JWT access token muddati qisqa saqlanadi, refresh token orqali yangilanadi.
• Bir necha marta noto'g'ri login urinishida vaqtinchalik bloklash qo'llaniladi.
10.2 Ma'lumotlar xavfsizligi
• Barcha muloqot HTTPS orqali amalga oshiriladi.
• Foydalanuvchi faqat o'z transaction va account ma'lumotiga kira oladi.
• Nozik ma'lumotlar loglarda ochiq ko'rinishda saqlanmaydi.
• Input validation va sanitization orqali NoSQL injection va XSS xavfi kamaytiriladi.
10.3 Sessiya va API himoyasi
• Protected endpointlar faqat autentifikatsiyadan o'tgan foydalanuvchi uchun ochiq bo'ladi.
• Rate limiting orqali ortiqcha requestlardan himoya qilinadi.
• CSRF xavfini kamaytirish uchun cookie strategiyasi ehtiyotkorlik bilan tanlanadi.
• Muhim amallar bo'yicha audit log yuritilishi tavsiya etiladi.
